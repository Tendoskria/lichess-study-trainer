# Piece set

SVG pieces "cburnett" by Colin M.L. Burnett, taken from the
[Lichess repository](https://github.com/lichess-org/lila/tree/master/public/piece/cburnett),
licensed under **GPL-2.0-or-later**.

Modification: the outline of the white pieces was thinned (`stroke-width` 1.5 → 1).

To use another set, replace the twelve files (`wK.svg` … `bP.svg`) — the code only relies on
these names. Mind the license of the set you pick.
